========================================================================
            懒人听书缓存批量转换工具 —— 使用说明
========================================================================

【它做什么】
把华为手机(此电脑 → Mate 20)上「懒人听书」App 的加密缓存，批量解密、
转码成可直接播放的 MP3，输出到电脑上，并可选删除手机端缓存。

  手机缓存位置(自动读取，两个位置都会扫)：
    内部存储\Android\data\bubei.tingshu\files\down
    存储卡  \Android\data\bubei.tingshu\files\down

------------------------------------------------------------------------
【三步流程 —— 每步背后发生了什么】
------------------------------------------------------------------------
第 1 步  复制到本地(提速关键)
    · 脚本把选中小说的缓存文件从手机复制到电脑的本地文件夹
    · 采用「批量并行复制」：一次投递多个复制任务，Shell 复制队列持续有活干；
      同时用本地磁盘扫描判断完成，不再逐个去枚举手机目录(那样最慢)
    · 复制完成后才进入第 2 步 —— 复制与转换彻底分开，避免边复制边等
    · 已复制过的文件自动跳过，中断后重跑可续传(不会重复搬)

第 2 步  解密转换
    · 自动调用「懒人听书音频批量转换.exe」(已内嵌在 tools\ 目录里)
    · 程序启动后会弹出「选择文件夹」对话框，脚本自动填入路径并点击确认，
      工具解密完成后自行退出，加密缓存随之从工作目录消失(天然增量)
    · 注意：转换工具的原始产物扩展名虽然叫 .mp3，实际是 MP4/AAC 容器

第 3 步  转码为真正的 MP3(并行)
    · 用本机 ffmpeg 把上一步的结果转成真正的 MP3(默认 96kbps)
    · 同时写入 ID3 标签：标题=集名、专辑=书名、艺术家=主播、作曲=作者
      (作者/主播来自「联网核对」的结果，没核对过则只写标题与专辑)
    · 多个 ffmpeg 进程并行(默认 6 个)，比逐个转码快数倍
    · 转码成功即删掉中间产物，输出目录只留 MP3

------------------------------------------------------------------------
【输出在哪里】
------------------------------------------------------------------------
  软件目录\workspace\<书名>\第XXX集_剧集名.mp3

  · 默认就是软件文件夹内的 workspace 目录，每本小说一个子文件夹
  · 一集一个文件，文件名含集数与标题，播放器里就是正常的剧集列表
  · 界面上的「输出目录」框可以改成别的位置(不填就是默认的 workspace)

【删除手机端缓存 —— 请务必看清楚】
------------------------------------------------------------------------
  · 方式一：勾选小说 → 点「删除手机缓存」→ 连续两次确认
  · 方式二：勾选底部「转换成功后删除手机缓存」，转换成功后自动删除
  · 删除是【永久删除】，手机上不进回收站、无法撤销；
    删除的是手机里「懒人听书」的缓存文件夹，本地已转好的 MP3 不受影响
  · 程序会在删除后自动确认系统弹出的删除对话框；若手机缓存已被 App
    重新占用(正在播放/正在下载)，删除可能失败，日志里会写明原因
  · 建议：先转换成功、确认本地 MP3 正常播放后，再删除手机缓存

------------------------------------------------------------------------
【联网核对(可选)】
------------------------------------------------------------------------
  · 数据来源：懒人听书官网公开页面(免登录)
  · 得到：官网总集数、连载中/已完结、作者、主播
  · 与本地集数对比后给出结论，例如：
      官网共 1401 集, 已完结; 本地 1399 集, 缺 2 集
  · 结果缓存 24 小时(online_cache.json)，重复核对不再联网
  · 官网有访问频率限制：连续大量请求会被临时限流，
    程序会自动退避重试、冷却后继续；被限流的书下次会自动重查

------------------------------------------------------------------------
【只下载指定的集 —— 集数范围(可按每本小说单独设置)】
------------------------------------------------------------------------
  用途：手机空间不够、或只想先听某一段时，可以只把指定集数复制、转换到电脑。

  两种设置方式：
    ① 批量：先在列表里勾选若干本小说 → 在「集数范围」栏填
       「第 700 集 ～ 第 717 集」→ 点「应用到勾选本」
    ② 单本：双击列表里的那一行（或点该分区下方的「设范围…」）→ 填起止集号

  填写规则：
    · 两端都留空      = 全部(不限制)
    · 只填起始(700)   = 第700集起(≥700)
    · 只填结束(300)   = 到第300集为止(≤300)
    · 起止填反了会自动交换；集号必须是正整数

  生效范围(重要)：
    · 只把该区间内的缓存从手机复制到电脑，区间外的手机文件不动、不复制
    · 本地已有的区间外文件也不会被转码，原样保留
    · 解析不出集号的条目(片花、番外)不受限制，始终会被复制过来
    · 范围只决定"这次处理哪些集"，不会删除任何已转好的 MP3

  举例：某本书只想补第 700~717 集
    勾选该书 → 起始填 700、结束填 717 → 应用到勾选本 → 开始转换
    日志里会写明「集数范围：第700~717集（范围外跳过 N 个）」

【常见问题】
------------------------------------------------------------------------
Q: 提示「未检测到手机」？
A: 用 USB 线连接手机，在手机通知栏把 USB 用途选成「传输文件(MTP)」，
   再点「刷新列表」。部分机型需同时开启「USB 调试」或解锁屏幕。

Q: 界面上集数是「…」或「?」？
A: 「…」表示还在统计，「?」表示读取该文件夹失败(通常是手机端正在读写)。

Q: 日志提示找不到 ffmpeg，只能输出 MP4？
A: 本机 ffmpeg 在 D:\ffmpeg-2025-03-17-...\bin\ffmpeg.exe。
   若该路径变了，把 ffmpeg.exe 复制到本软件的 tools\ 目录即可被自动识别。
   没有 ffmpeg 时程序会保留转换工具的原始输出(MP4 容器，也能播放)。

Q: 转换到一半关掉了界面，会白做吗？
A: 不会。已复制的缓存在 workspace 里；已转好的 MP3 也在。
   重新勾选同一本书再跑，已存在的会自动跳过，只补没做完的。

Q: 设置了集数范围，以前转好的其它集会丢吗？
A: 不会。范围只决定"这次从手机复制哪些集、转码哪些集"，
   本地已有的、区间外的文件一律原样保留，既不删除也不改动。

Q: 为什么手机上同一本书有两个缓存文件夹？
A: 内部存储与存储卡各有一份(有时存储卡上还有另一版本、集数编号不同)。
   界面左右两个分区会分别列出；两边的文件都会被复制合并到同一个输出目录。

Q: 作者/主播列是空的？
A: 需要先做一次「联网核对」；未匹配到官网条目的书不会显示作者与主播。

【命令行用法(可选)】
------------------------------------------------------------------------
  python lanren_convert.py --list               只列出手机上的小说
  python lanren_convert.py --list --online      列出并联网核对集数/作者/主播
  python lanren_convert.py --all                转换全部
  python lanren_convert.py --name 大明官         只转换名字含「大明官」的
  python lanren_convert.py --name 大明官 --limit 3   每本只处理前 3 集(测试用)
  python lanren_convert.py --name 大明官 --range 700-717   只处理第700~717集
  python lanren_convert.py --range 700-      只处理第700集之后的(≥700)
  python lanren_convert.py --range -300      只处理到第300集(≤300)
  python lanren_convert.py --out D:\听书          指定输出目录
  python lanren_convert.py --all --delete-phone  转换成功后删除手机端缓存
