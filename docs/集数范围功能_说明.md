# 集数范围功能（按每本小说指定只下载第几集~第几集）

> 改动日期：2026-10-05　|　涉及文件：`lanren_convert.py`、`lanren_gui.py`、`使用说明.txt`
> 备份：`_backup\lanren_convert.py.1005_070727.bak`、`_backup\lanren_gui.py.1005_070727.bak`

---

## 1. 需求

原来一本书要么全下、要么不下。现在可以**给每本小说单独指定一个集数区间**，
比如「《步步生莲》只要第 700~717 集」，程序就只把这些集从手机复制、解密、转码到本地，
手机上的其它文件不动、本地已有的其它集也不碰。

---

## 2. 怎么用

### 界面（三种方式，任选）

| 方式 | 操作 | 适合 |
|---|---|---|
| 批量 | 先勾选若干本 → 在「集数范围」栏填 `第 [700] 集 ～ 第 [717] 集` → 点 **应用到勾选本** | 一次给多本设同一个范围 |
| 单本① | **双击**列表里的那一行 → 弹窗填起止集号 | 只调一本 |
| 单本② | 选中该行 → 点该分区下方的 **「设范围…」** | 同上，更好找 |

- 列表新增 **「范围」列**，实时显示每本书的范围：`全部` / `700-717` / `≥700` / `≤300`
- **清除范围**：有勾选就只清勾选的，没勾选就清全部（回到「全部」）
- 填了非法值（如 `abc`、`0`）会弹错误框且**不会改坏原有设置**

### 命令行

```bat
python lanren_convert.py --name 大明官 --range 700-717    只处理第700~717集
python lanren_convert.py --all --range 700-              第700集起
python lanren_convert.py --all --range -300              到第300集为止
python lanren_convert.py --all --range 700至717           也支持「至」
```

---

## 3. 生效范围（语义，重要）

**范围 = "这一次处理哪些集"，不是"保留哪些集"。**

| 对象 | 会不会被处理 |
|---|---|
| 区间内的手机缓存 | ✅ 复制 → 解密 → 转码 |
| 区间外的手机缓存 | ❌ 不复制（手机文件原封不动） |
| 区间外、但本地已存在的文件 | ❌ 不转码、不改名、**不删除**，原样保留 |
| 解析不出集号的条目（**片花、番外**） | ✅ **始终会被复制**（宁滥勿缺，避免误丢非正片内容） |

- 两端可留空：`700-`（≥700）、`-300`（≤300）；两端都空 = 全部
- 起止填反了**自动交换**
- 日志会写明：`集数范围：第700~717集（范围外跳过 N 个）`

## 4. 代码改动

### `lanren_convert.py`（核心）

| 新增 / 变更 | 说明 |
|---|---|
| `parse_episode(text)` | 从解码后的集名解析集号。先匹配 `第NNN集`，再退回第一个数字串 → 同时兼容 `第001集_天下`、`北宋大丈夫001  标题`、`黄金瞳-第812集` |
| `norm_ep_range(rng)` | 规范化区间：去空、交换倒置、两端全空→`None`、非法集号抛 `ValueError` |
| `in_ep_range(name, rng)` | 区间判定；**解析不出集号的一律放行** |
| `ep_range_text(rng)` | 区间 → 展示文本（`第700~717集` / `第700集起` / `全部`） |
| `parse_range_arg(s)` | 解析 `700-717` / `700-` / `-717` / `700至717` 这类字符串（命令行用） |
| `collect_source_files(...)` | **签名变更**：新增 `ep_range=`；返回值由 `list` 改为 **`(items, skipped)` 二元组** |
| `transcode_in_place(...)` | 新增 `ep_range=`；区间外的文件（含遗留 `.__tmp.mp3`）直接跳过，计入 `stat["skipped"]` |
| `process_novel(...)` | 新增 `ep_range=`；`stat` 新增 `ep_range` / `range_skipped`；区间非法时直接以 `error` 返回 |
| `main()` | 新增 `--range` 参数 |

> ⚠️ **`collect_source_files()` 的返回值变了**（原来是只返回 list）。
> 项目内只有 `process_novel` 调用它，已同步修改；若外部脚本调用过它，需要改成解包两个值。

### `lanren_gui.py`（界面）

- 列表新增第 6 列 **「范围」**（列序：勾选 / 小说名 / 本地 / 官网 / 状态 / **范围** / 作者 / 主播）
- 新增 **「集数范围」** 工具条：起始/结束输入框 + `应用到勾选本` + `清除范围`
- 新增 **单本范围对话框**（双击行 / 「设范围…」按钮），支持 `确定` / `清空(全部)` / `取消`，
  Esc 关闭、回车确认
- 每本范围的记录挂在 `self.books[vol][name]["range"]`，`start()` 汇总成 `ranges` 传给转换线程
- 新按钮纳入 `_set_busy()`，转换期间自动禁用
- 窗口尺寸 1120×780 → **1240×820**（容纳新列），最小尺寸同步放宽

## 6. 注意事项

1. **改完必须重启界面才生效** —— Python 在启动时加载代码，已开着的窗口跑的还是旧代码。
2. 范围只影响「复制哪些集」和「转码哪些集」，**绝不会删除**任何已转好的 MP3。
3. 勾了「转换成功后删除手机缓存」时，删除的是**整本**的缓存文件夹
   （不是只删区间内那些）—— 若只想处理一部分，建议先别开这个开关。
4. 片花 / 番外这类解析不出集号的条目会**始终**被复制，属预期行为。
